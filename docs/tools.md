# Tool reference

Generated by `solidworks-mcp --tools-md` (version 0.1.0). 131 tools.

Units: mm, degrees, kg. Geometry references: `{id}`, `{at:[x,y,z]}`, `{name}`, `{where:{…},expect:n}`.

## session

### `dialog_list` — List SOLIDWORKS dialogs (read-only, idempotent)

Lists visible SOLIDWORKS dialogs (handle, title, text, buttons) and whether one blocks SOLIDWORKS. Works while SOLIDWORKS is blocked. Use it after DIALOG_BLOCKING or TIMEOUT, and tell the user what the dialog says.

### `dialog_respond` — Answer a SOLIDWORKS dialog (destructive)

Presses a button on a SOLIDWORKS dialog by its handle (from dialog_list). Use it only for dialogs your own call caused, or when the user told you how to answer. Answers that can discard work (Don't Save, Discard, Delete, Replace, No on a save prompt) need confirm=true, which requires the user's approval. Works while SOLIDWORKS is blocked.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `handle` | string | yes | Dialog handle from dialog_list, e.g. "0x1A2B3C". |
| `button` | string | yes | Button caption as shown (e.g. "OK", "Cancel", "End", "Yes"); "ok"/"cancel" also work on dialogs without that caption. |
| `confirm` | boolean |  | Required for answers that can discard work; only with the user's approval. Default: `false`. |

### `sw_connect` — Connect to SOLIDWORKS (idempotent)

Attach to the running SOLIDWORKS (normally automatic), or start it with launch=true (takes a license seat and up to 3 minutes). Never starts a second instance. Reports the revision and any preferences recovered from a crashed session.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `launch` | boolean |  | Start SOLIDWORKS if it is not running. Only when the user asked for it. Default: `false`. |

### `sw_help` — Help and guides (read-only, idempotent)

Help, guides and recipes for this server: conventions (units, axes, points, documents), entityref (referencing faces, edges and planes), workflow_plate, workflow_enclosure, editing (existing parts, STEP files), recovery (every error code and what to do), tools (all tools with their parameters). Without a topic: the index. Makes no SOLIDWORKS call.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `topic` | string |  | conventions \| entityref \| workflow_plate \| workflow_enclosure \| editing \| recovery \| tools; default: the index. |

### `sw_status` — SOLIDWORKS status (read-only, idempotent)

Status of the SOLIDWORKS connection: version, open documents (handle, owned/adopted/foreign, dirty), the target document, open sketch, visible dialogs, whether a modal dialog blocks SOLIDWORKS, the running operation and recentOps (what happened to calls that timed out). Never hangs: works even while SOLIDWORKS is busy. Call it first, and after any TIMEOUT.

## documents

### `doc_activate` — Activate document (idempotent)

| Parameter | Type | Required | Description |
|---|---|---|---|
| `doc` | string | yes | Handle (D2), title or path of an open document. |

### `doc_close` — Close document (destructive)

Closes a document this server owns (or the user allowed). A document with unsaved changes needs save=true or discard=true (discard only for documents this server created). The user's own documents are never closed.

| Parameter | Type | Required | Description |
|---|---|---|---|

| `discard` | boolean |  | Throw away unsaved changes (owned documents only). Default: `false`. |

### `doc_list` — List documents (read-only, idempotent)

Lists open documents: handle (D1…), title, path, type, dirty, access (owned = created by this server; adopted = the user allowed edits; foreign = the user's, read-only), active and target flags, units.

### `doc_new` — New document

Creates a new part, assembly or drawing (owned by this server) and makes it the target document. Units default to MMGS (mm, g, s) whatever the template says. A drawing starts as A3 landscape, ISO sheet format, first angle, 1:1 (drw_sheet_setup changes it).

| Parameter | Type | Required | Description |
|---|---|---|---|
| `type` | string |  | part \| assembly \| drawing Default: `"part"`. |
| `units` | string |  | mmgs (default) \| cgs \| mks \| ips \| template (keep the template's units). Default: `"mmgs"`. |
| `template` | string |  | Optional template file (.prtdot/.asmdot/.drwdot); default: the user's default template. |
| `name` | string |  | Optional document name (used as the file name when saved). |

### `doc_open` — Open or import a file

Open a file: .sldprt/.sldasm/.slddrw opens silently without a rebuild prompt; STEP/IGES/Parasolid/SAT/STL is imported as a new part (or assembly) with MMGS units and its bodies verified. The document becomes the target and this server may edit it. A file that is already open is not reopened: it becomes the target with alreadyOpen=true and keeps its access (the user's documents stay read-only). Reports load warnings (missing references, read-only, newer version) and, for imports, bodies and volume.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `path` | string | yes | File to open or import; relative paths are under Documents\solidworks-mcp. |
| `readOnly` | boolean |  | Open a SOLIDWORKS file read-only (changes need doc_save mode copy/as). Default: `false`. |
| `configuration` | string |  | Part/assembly configuration to open; default: the one last saved. |

| Parameter | Type | Required | Description |
|---|---|---|---|
| `mode` | string |  | inPlace \| as \| copy Default: `"inPlace"`. |
| `path` | string |  | Target file for as/copy (.sldprt/.sldasm; the extension is added if missing). |

| `doc` | string |  | Document (handle, title or path); default: the target document. |

### `doc_undo` — Undo (destructive)

Undoes the last SOLIDWORKS undo steps (one feature creation is one step), only in documents this server may edit, only while nobody else changed them since the server's last change, and never more steps than the server made. Returns the features removed or restored and the volume change.

| Parameter | Type | Required | Description |

### `sketch_add` — Add sketch entities

Any kind: construction, label. Returns segment names per entity (rectangle sides named) and the contour status (closed loops are needed for extrudes).

| Parameter | Type | Required | Description |
|---|---|---|---|
| `entities` | array | yes | Entities to draw, e.g. [{"kind":"rectangle","center":[0,0],"widthMm":100,"heightMm":60}]. |

### `sketch_offset` — Offset sketch segments

| Parameter | Type | Required | Description |

| `distanceMm` | number | yes | Offset distance in mm. |
| `side` | string |  | Closed loop: outward \| inward \| both. Open chain: left \| right \| both. Default: `"outward"`. |

### `sketch_pattern` — Sketch pattern

Copies entities of the open sketch in a pattern. linear: countX instances spacingXMm apart along angleDeg (0 = sketch +x), optionally countY rows spacingYMm apart at +90 deg. circular: count instances about center, evenly around a full circle (totalAngleDeg 360) or spanning a smaller angle, counter-clockwise (negative = clockwise). Counts include the seed. Verified: the copies lie at the predicted positions; otherwise undone.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `kind` | string | yes | linear \| circular |
| `entities` | array | yes | Segments (or points) to copy, e.g. [{name:'Arc1'}]. |
| `countX` | integer |  | linear: instances along the first direction. |
| `spacingXMm` | number |  | linear: spacing along the first direction, mm. |
| `countY` | integer |  | linear: instances along the second direction (default 1). |
| `spacingYMm` | number |  | linear: spacing along the second direction, mm. |
| `angleDeg` | number |  | linear: first direction in degrees from sketch +x (default 0). |
| `center` | array |  | circular: center [x,y] sketch mm. |
| `count` | integer |  | circular: number of instances. |
| `totalAngleDeg` | number |  | circular: 360 = full circle; less = the angle from the seed to the last instance (at most 360·(count-1)/count); negative = clockwise. Default: `360`. |
| `doc` | string |  | Document (handle, title or path); default: the target document. |

### `sketch_relation_add` — Add sketch relation
