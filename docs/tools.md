# Tool reference

Generated by `solidworks-mcp --tools-md` (version 0.1.0). 21 tools.

Units: mm, degrees, kg. Geometry references: `{id}`, `{at:[x,y,z]}`, `{name}`, `{where:{…},expect:n}`.

## session

### `dialog_list` — List SOLIDWORKS dialogs (read-only, idempotent)

Lists visible SOLIDWORKS dialogs (handle, title, text, buttons) and whether one blocks SOLIDWORKS. Works while SOLIDWORKS is blocked. Use it after DIALOG_BLOCKING or TIMEOUT, and tell the user what the dialog says.

### `dialog_respond` — Answer a SOLIDWORKS dialog (destructive)

Presses a button on a SOLIDWORKS dialog by its handle (from dialog_list). Use it only for dialogs your own call caused, or when the user told you how to answer. Answers that can discard work (Don't Save, Discard, Delete, Replace, No on a save prompt) need confirm=true, which requires the user's approval. Works while SOLIDWORKS is blocked.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `handle` | string | yes | Dialog handle from dialog_list, e.g. "0x1A2B3C". |
| `button` | string | yes | Button caption as shown (e.g. "OK", "Cancel", "End", "Yes"); "ok"/"cancel" also work on dialogs without that caption. |
| `confirm` | boolean |  | Required for answers that can discard work; only with the user's approval. Default: `false`. |

### `sw_connect` — Connect to SOLIDWORKS (idempotent)

Attach to the running SOLIDWORKS (normally automatic), or start it with launch=true (takes a license seat and up to 3 minutes). Never starts a second instance. Reports the revision and any preferences recovered from a crashed session.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `launch` | boolean |  | Start SOLIDWORKS if it is not running. Only when the user asked for it. Default: `false`. |

### `sw_status` — SOLIDWORKS status (read-only, idempotent)

Status of the SOLIDWORKS connection: version, open documents (handle, owned/adopted/foreign, dirty), the target document, open sketch, visible dialogs, whether a modal dialog blocks SOLIDWORKS, the running operation and recentOps (what happened to calls that timed out). Never hangs: works even while SOLIDWORKS is busy. Call it first, and after any TIMEOUT.

## documents

### `doc_activate` — Activate document (idempotent)

Makes a document active and the session's target. With allowEdit=true, a user document becomes editable for this server (a backup copy is saved first) — only do this when the user asked you to change that document.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `doc` | string | yes | Handle (D2), title or path of an open document. |
| `allowEdit` | boolean |  | Allow this server to modify the user's document (never discard or rename it). Default: `false`. |

### `doc_close` — Close document (destructive)

Closes a document this server owns (or the user allowed). A document with unsaved changes needs save=true or discard=true (discard only for documents this server created). The user's own documents are never closed.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `save` | boolean |  | Save before closing (the document must already have a file). Default: `false`. |
| `discard` | boolean |  | Throw away unsaved changes (owned documents only). Default: `false`. |
| `doc` | string |  | Document (handle, title or path); default: the target document. |

### `doc_list` — List documents (read-only, idempotent)

Lists open documents: handle (D1…), title, path, type, dirty, access (owned = created by this server; adopted = the user allowed edits; foreign = the user's, read-only), active and target flags, units.

### `doc_new` — New document

Creates a new part or assembly (owned by this server) and makes it the target document. Units default to MMGS (mm, g, s) whatever the template says.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `type` | string |  | part \| assembly Default: `"part"`. |
| `units` | string |  | mmgs (default) \| cgs \| mks \| ips \| template (keep the template's units). Default: `"mmgs"`. |
| `template` | string |  | Optional template file (.prtdot/.asmdot); default: the user's default template. |
| `name` | string |  | Optional document name (used as the file name when saved). |

### `doc_save` — Save document (destructive)

Saves the target document. mode: inPlace (existing file), as (Save As: the document becomes the new file; owned documents only) or copy (writes a copy, the document is unchanged). Relative paths go under Documents\solidworks-mcp. Existing files need overwrite=true (a file this server didn't write is backed up first). Verifies the file was written.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `mode` | string |  | inPlace \| as \| copy Default: `"inPlace"`. |
| `path` | string |  | Target file for as/copy (.sldprt/.sldasm; the extension is added if missing). |
| `overwrite` | boolean |  | Replace an existing file. Default: `false`. |
| `doc` | string |  | Document (handle, title or path); default: the target document. |

## inspect

### `edge_list` — List edges (read-only, idempotent)

Edges matching a filter, each with an id, curve type, length, start/end/mid points (mid resolves back to the edge), and radius/center/axis for circles. Filter examples: {curve:'line', parallelTo:'y'} (vertical edges), {ofFace:{id:'F2'}, loop:'outer'}, {curve:'circle', radiusMm:5}, {feature:'Boss-Extrude1'}.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `where` | object |  | Filter: curve, parallelTo, radiusMm, lengthMm, ofFace (+loop), near+withinMm, extreme, feature, body, component. |
| `limit` | integer |  | Maximum edges (1-1000). Default: `50`. |
| `offset` | integer |  | Edges to skip (paging). Default: `0`. |
| `withFaces` | boolean |  | Also report the ids of the two faces each edge joins. Default: `false`. |

| Parameter | Type | Required | Description |

## sketch

### `sketch_add` — Add sketch entities

Draws entities in the open sketch, all or nothing. Points: [x,y] sketch mm or [x,y,z] model mm (projected). Kinds and fields: line/centerline {from,to}; polyline {points,closed}; rectangle {corners:[p1,p2]} or {center,widthMm,heightMm}; circle {center,radiusMm|diameterMm}; arc {start,mid,end} or {center,radiusMm,startDeg,endDeg} (CCW); slot {from,to,widthMm}; polygon {center,sides,circumradiusMm|inradiusMm,rotationDeg}; ellipse {center,majorRadiusMm,minorRadiusMm,rotationDeg}; spline {points}; point {at}. Any kind: construction, label. Returns segment names per entity (rectangle sides named) and the contour status (closed loops are needed for extrudes).

| Parameter | Type | Required | Description |
|---|---|---|---|
| `entities` | array | yes | Entities to draw, e.g. [{"kind":"rectangle","center":[0,0],"widthMm":100,"heightMm":60}]. |
| `doc` | string |  | Document (handle, title or path); default: the target document. |

### `sketch_finish` — Finish sketch

Closes the open sketch. Returns its segment and relation counts, constrained status and contour status (closed/open loops, regions). The next feature tool uses this sketch by default.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `doc` | string |  | Document (handle, title or path); default: the target document. |

### `sketch_start` — Start sketch

Opens a new sketch on a plane ({name:'top'|'front'|'right'} or a plane's name) or on a planar face ({id:'F3'} or {at:[x,y,z]}). Returns the sketch name and its frame in model space (origin, x axis, y axis, normal), and for a face its extents in sketch coordinates. Inference snapping is off while this server draws.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `on` | object |  | Plane or planar face to sketch on. |
| `threeD` | boolean |  | Open a 3D sketch instead (points are then model [x,y,z]). Default: `false`. |
| `doc` | string |  | Document (handle, title or path); default: the target document. |

## features

### `feature_extrude` — Extrude (boss or cut)

Extrudes a closed sketch profile into a boss, or cuts it (cut=true). Uses the open/last sketch unless 'sketch' is given. Verified: the feature exists without errors, the volume grew (boss) or shrank (cut), and the end cap lies at the requested depth; otherwise it is rolled back. Returns the feature, its dimensions (e.g. D1@Boss-Extrude1), the new faces with ids and the model extents.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `depthMm` | number |  | Depth in mm (blind; total thickness for mid_plane). |
| `end` | string |  | blind \| through_all \| through_all_both \| mid_plane Default: `"blind"`. |
| `cut` | boolean |  | Cut material instead of adding it. Default: `false`. |
| `direction` | string |  | normal (along the sketch normal) \| reverse \| auto (cuts: into the material, the default) \| a model axis like "+y" \| "x,y,z". |
| `sketch` | string |  | Sketch to extrude (default: the open sketch, else the last finished one). |
| `merge` | boolean |  | Merge the result with existing bodies (boss). Default: `true`. |
| `draftDeg` | number |  | Draft angle in degrees (0 = none). |
| `draftOutward` | boolean |  | Draft outward instead of inward. Default: `false`. |
| `name` | string |  | Rename the new feature. |
| `keepOnFailure` | boolean |  | Keep the feature even if verification fails (for diagnosis). Default: `false`. |
| `doc` | string |  | Document (handle, title or path); default: the target document. |

### `feature_fillet` — Fillet

Rounds edges (and/or all edges of faces) with a constant radius. Edges by id, point or query, e.g. edges:[{where:{curve:'line', parallelTo:'y'}, expect:4}]. Verified: the fillet exists without errors, changed the volume (concave edges add material, convex remove it) and has a round face of that radius; otherwise rolled back.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `radiusMm` | number | yes | Fillet radius in mm. |
| `edges` | array |  | Edges to round. |
| `faces` | array |  | Faces whose edges are all rounded. |
| `propagate` | boolean |  | Also round tangent-connected edges. Default: `true`. |
| `name` | string |  | Rename the new feature. |
| `keepOnFailure` | boolean |  | Keep the feature even if verification fails (for diagnosis). Default: `false`. |
| `doc` | string |  | Document (handle, title or path); default: the target document. |

## automation

### `vba_run` — Run VBA (last resort) (destructive, open-world)

Runs SolidWorks BASIC code (VBA-like) inside SOLIDWORKS — a last resort when no tool fits. Off unless the user set SWMCP_VBA=on. The API inside uses METERS and RADIANS: helpers MM(x) and DEG(a) convert. Predefined: swApp, swDoc (the target document), Echo(text) for output. Declare variables with Dim x As Object/Double/Long/String; don't name anything Log, Imp, Eqv or Mod. Returns the output, errors (trapped or from the error dialog), whether it compiled, and features added.

| Parameter | Type | Required | Description |
|---|---|---|---|
| `code` | string | yes | Statements to run (the body of a Sub; no Sub/End Sub needed). |
| `timeoutS` | integer |  | Time limit in seconds (5-600). Default: `50`. |
| `doc` | string |  | Document (handle, title or path) bound to swDoc; default: the target document. |
